➕ Nuevo producto

📘 ¿Cómo cargo un producto? Guía rápida con ejemplo
  1. Completá Nombre, Precio de venta, Stock actual y Stock mínimo (obligatorios). Marca y Categoría son opcionales.
  2. Presioná Guardar producto una sola vez. Mientras se procesa, el botón muestra un círculo giratorio y se bloquea: esperá el mensaje verde de confirmación.
  3. Si algún dato no es válido, aparece un mensaje en rojo debajo del campo que hay que corregir. Corregilo y volvé a guardar.
  4. Si aparece un aviso de conexión o demora, no vuelvas a cargarlo enseguida: revisá primero la tabla de Inventario para ver si el producto ya se guardó.
  5. Para modificar un producto usá Editar en la tabla. El stock actual no se cambia desde acá: se ajusta con un movimiento (pestaña Movimientos).
